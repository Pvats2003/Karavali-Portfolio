The Problem

Every Manipal student asks
the same question.

"Where should we go this weekend?" — and nobody has a good answer. No reliable guide. No community knowledge. Just WhatsApp chaos.

🗺️
No reliable local guide
Google Maps shows tourist spots. Students need student-verified, hyperlocal truth — which chai stall is open at 1am, which beach is empty on Tuesdays.
👥
Group decisions are painful
Getting 6 people to agree on where to go takes longer than the actual outing. No tool solves this for student groups in India.
🌊
Students graduate having missed it
Manipal has incredible spots within 30 minutes. Most students discover them in year 3 or 4 — or not at all. 4 years of missed experiences.
😔
FOMO without direction
Students see Instagram stories and feel left out — but don't know where to actually go. The gap between knowing and doing is the problem.

AI Architecture

Not just an API call.
Actual agents.

Two multi-step agentic pipelines built from scratch. Real tool use. Real decision loops. Real safety layers.

1
Intent Parsing
Claude extracts structured parameters from user input as strict JSON — duration, budget, vibe, group size, time of day
2
Real Data Fetch
Supabase query + OpenWeatherMap API run in parallel, filtered by extracted parameters
3
Synthesis
Claude builds itinerary using only real Karavali places returned from database — zero hallucinated locations
4
Output
Verified itinerary linking directly to real place detail pages inside the app
Agent 1 · Phase 1
Trip Planning Agent
A 4-step pipeline that parses user intent as JSON, fetches real matching places from Supabase, checks live weather via OpenWeatherMap, then synthesises an itinerary using only verified Karavali locations. Every stop links to a real place page. No hallucinated restaurants. No fake beaches. Includes a "Going with friends?" RSVP toggle that generates a shareable group link — the seed of Phase 3's group coordination vision.
Agent 2 · Phase 2
Mahi — Emotion Detection Agent
A 4-step safety-critical pipeline for student mental health support. Designed for Phase 2 launch — requires campus presence and real user trust before deployment.

Defensibility

Why this can't be
copied or replaced.

🔥
Trending This Week
Score = check-ins × 3 + photos × 2 + upvotes × 1. Real student activity. Updates automatically. ChatGPT has none of this.
💬
Senior Tips by Batch Year
"Go on Tuesday evening — no crowd." "Carry cash, no UPI after 9pm." Ground truth no AI model has in its training data.
👣
Real Check-in Data
Which places students actually visit — not what Google thinks is popular. Every check-in improves the platform for the next user.
🫶
Reaction Intelligence
60% Worth It tells you more than 4.2 stars. Reaction distributions reveal place character in ways star ratings never can.
The data moat grows with every student who uses it.
Classic community network effect. Each new user makes the platform more valuable for every other user. The more students check in, tip, and react — the more accurate and irreplaceable Karavali's intelligence becomes.
