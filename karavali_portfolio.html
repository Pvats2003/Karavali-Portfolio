AI Architecture

Not just an API call.
Actual agents.

Two multi-step agentic pipelines built from scratch. Real tool use. Real decision loops. Real safety layers.

1
Intent Parsing
Claude extracts structured parameters from user input as JSON
→
2
Real Data Fetch
Supabase query + Weather API run in parallel based on parameters
→
3
Synthesis
Claude builds itinerary using only real verified Karavali places
→
4
Output
Verified itinerary with place links — zero hallucinated locations
Agent 1
Trip Planning Agent
A 4-step pipeline that parses user intent, fetches real places from Supabase matching the parameters, checks live weather, then synthesises an itinerary using only verified Karavali locations. Every itinerary links directly to real place pages. No hallucinated restaurants. No fake beaches.
Agent 2 — Mahi
Emotion Detection Agent
A 4-step safety pipeline: emotion classification → contextual resource retrieval → level-adaptive response generation → safety validation. Crisis-level messages trigger a UI override with direct emergency contacts. A safety reviewer Claude call checks every Level 3-4 response before it reaches the user.

"Go on Tuesday evening — no crowd." "Carry cash, no UPI after 9pm." Ground truth that no AI model has in its training data.

vs Word of mouth: Karavali captures and scales what used to die in individual WhatsApp conversations.
vs Any new competitor: They'd need years of student check-ins, tips, and reactions to match what Karavali builds in its first semester.
